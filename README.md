# Personal Portfolio Web Application

Responsive portfolio built with HTML5, CSS3, Bootstrap 5 and JavaScript (ES6+).

## Features
- Semantic sections: Home, About, Education, Skills, Projects, Contact
- Mobile-first responsive layout (media queries, Bootstrap grid)
- Bootstrap navbar, cards, buttons, table, form and alerts
- Dark/light theme switch (saved in localStorage)
- Project filtering by category
- Contact form with client-side validation and success/error messages

## How to run
Open `index.html` in any browser (internet needed for Bootstrap CDN).

## Folder structure
- index.html  - page structure
- style.css   - custom styles
- script.js   - interactivity
- assets/     - images
